## 📋 技术细节

### edge-tts音频生成失败问题

**现象**：运行`fix_timing_v25.py`时，第4页（索引3）起音频生成失败（输出0字节文件）。

**可能原因**：
1. 某些文本的引号/特殊字符导致edge-tts API失败
2. edge-tts服务限流（批量请求被限制）
3. asyncio事件循环问题

**尝试过的方案**：
- ✗ 加重试逻辑（retry 3次）→ 仍然失败
- ✗ 修改脚本OUT路径到C盘 → 绕过沙箱限制，但音频生成仍失败
- ✗ 用`python -u`（无缓冲输出）→ 能看到日志，但音频生成仍失败

**未尝试的方案**：
- 用命令行工具`edge-tts-cli`（需要安装）
- 换用其他TTS服务（需要付费API）
- 手动检查每页文本，移除特殊字符后重试

### 沙箱权限问题

**现象**：脚本试图在E盘创建`audio_lines_v25/`目录时，被沙箱阻止（Permission denied）。

**解决方案**：修改脚本OUT路径到C盘（`C:/Users/Mary/WorkBuddy/2026-05-17-task-4/regenerate/book-XXX`）。
